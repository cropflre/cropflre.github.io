Nowen Note 快速入口

第一次使用，建议按下面三步先跑通核心链路。

01 · START

5 分钟快速上手

部署、登录、创建目录、写下第一篇笔记，再完成第一份备份。

 02 · WRITE

富文本与 Markdown

选择适合自己的编辑器，掌握图片、表格、代码、公式与 Mermaid。

 03 · HOST

Docker / NAS 部署

长期运行在绿联、飞牛、群晖或 Linux 服务器时要注意哪些数据和安全项。

 04 · AI

AI 配置与 RAG

接入 DeepSeek、Gemini、豆包、通义、OpenAI 兼容接口或 Ollama。

 05 · DATA

备份与恢复

理解完整备份包含什么，以及升级、迁移前必须做的恢复准备。

 06 · SUPPORT

常见问题排查

客户端连接、登录、图片附件、同步冲突和性能问题从哪里开始查。
