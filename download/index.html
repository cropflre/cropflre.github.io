弄文笔记是一款开源笔记与知识管理工具，支持 Markdown、富文本、AI、任务管理，以及 NAS / Docker 自托管。选择你的设备，找到正确的正式安装包。

打开实时下载中心 → GitHub 正式 Releases ↗

实时下载中心会读取 GitHub 最新正式 Release，校验每个文件并提供按平台分类的下载链接。这里不固定某个版本号，避免新版本发布后给出过期安装包。
