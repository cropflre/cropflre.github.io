留言板隐私说明

更新于 2026 年 10 月 28 日 · 适用于 nowen.cn/guestbook/，不适用于 Nowen Note 客户端。

留言会保存什么？

提交后会保存昵称（可以匿名）、留言正文、随机留言编号、提交时间、审核状态；审核后还会保存官方回复和审核时间。通过审核的昵称、正文、时间、官方回复会对网站访客公开。未审核或被拒绝的内容不会公开展示。

反垃圾与数据处理

提交时需使用 Cloudflare Turnstile 人机验证；Worker 会向 Cloudflare 验证挑战令牌。限流会临时使用请求 IP 作为限制键，但 D1 留言表不存原始 IP、手机号、邮箱或站内账号。Cloudflare 作为基础设施服务方可能另外处理网络安全日志。请勿在留言中填入个人敏感信息。

保存多久，如何删除？

留言默认保留至管理员删除。你可以通过 官网 GitHub Issues 说明昵称和大致发布时间提出删除请求，管理员会核实后处理；请勿在公开 Issue 中发布身份证号、联系方式或其他敏感信息。

其他说明

留言区不能上传文件或图片；昵称并非实名认证。其他网站访问统计请参见 访问统计与隐私说明。
