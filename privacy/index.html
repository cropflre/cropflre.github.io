Windows 桌面版隐私政策

了解 Nowen Note 如何在本地、自托管服务器及你选择的第三方服务中处理数据。此文档适用于 Microsoft Store 与直接安装的 Windows 桌面版本。

最后更新：2026-10-15Windows 桌面应用Microsoft Store / EXE
隐私首先由你选择的使用方式决定

在本地使用时，笔记库主要保存在你的设备；连接自托管服务器、启用 AI、插件或云端备份后，相关数据才会流向所选服务。项目维护者不会因为你安装应用，就自动获得个人笔记数据。

01 · 适用范围和运营方

本政策适用于 Nowen Note（弄文笔记）Windows 桌面应用，包括从 Microsoft Store 安装的版本及同一桌面应用的直接分发版本。项目由 NOWEN 开源实验室（Nowen Note 项目维护者）维护。官方网站为 nowen.cn，源代码与问题反馈见 GitHub 项目。

Nowen Note 支持在个人电脑上本地使用，或连接用户及组织自行运营的服务器。自托管实例的运营者自行决定服务器端的数据处理、权限、保留期限及其法律义务；安装客户端并不意味着笔记会自动上传给项目维护者。如使用第三方部署的服务器，还应阅读该服务器运营者的隐私政策。

02 · 我们处理哪些数据

依照用户使用的功能，应用可能访问或处理以下信息：

  • 笔记与知识库内容：文本、Markdown、富文本、标签、文件夹、日记、任务、图片、附件、批注、分享内容及历史记录。
  • 账号和安全信息：用户名、登录凭证或会话令牌、服务器地址、账号权限、两步验证和 API Token 配置；密码与密钥不应公开分享。
  • 本地应用设置：偏好设置、窗口和更新状态、所选工作区、本地数据库及离线缓存。
  • 运行和诊断信息：应用版本、操作系统平台、错误和运行日志、崩溃转储文件；这些内容可能间接包含文件路径或其他敏感上下文。
  • 用户选择的集成数据：发送到 AI/Embedding 服务商的请求片段、插件获取的授权内容、同步或备份目的地所接收的文件。

应用不会为了笔记的基本本地编辑功能而要求读取你的通讯录或精确位置。对通过系统文件选择器打开、导入或保存的文件，应用仅为所请求的功能进行处理。

03 · 本地模式、存储和同步

本地模式：笔记数据库、附件、缓存、设置以及诊断日志可保存在设备用户数据目录或你配置的自定义数据目录。仅在本地使用时，不需要把完整笔记库上传到 NOWEN 官方服务器。

连接服务器和多端同步：当你配置并连接远程 Nowen Note 实例时，登录、数据同步、附件访问、协作和分享所需的信息会与指定服务器交换。服务器运营者可能处理账号、内容、访问时间、IP 地址及其他服务器日志，具体以其设置及隐私政策为准。

分享与协作：当你主动启用公开链接、邀请协作成员或对外授权时，相应内容可能被链接持有人或有权限的成员查看。请自行管理分享范围、有效期与密码。

04 · AI、知识检索和第三方模型

AI 写作、问答、Embedding、知识索引及相关自动化属于可选择使用的功能。当你使用这些功能，相关问题、选中的内容、当前笔记或检索到的知识片段，可能传输给你或所连接服务器管理员配置的模型/API 服务商。

知识库问答通常检索匹配片段，而非每次发送整个知识库；但建立向量索引时，已选择纳入索引的文档内容也可能传给在线 Embedding 服务。使用本地模型（例如自建 Ollama）可减少向第三方云模型发送内容。不同服务商的数据保留和使用规则以其自身政策为准。

请勿未经必要授权向 AI 服务输入他人的敏感资料、密码、证件号、助记词或机密信息。若不希望相关内容发往某个在线服务，请不要启用或使用该服务，或将其更换为本地部署的模型。

05 · 插件、附件与外部服务

当你主动安装、启用或授权插件及外部集成时，插件可在授予的权限范围内访问笔记、任务、附件或网络接口。插件的来源、权限和外部通信目标应由用户或服务器管理员审查；第三方插件可能具有独立的隐私条款。

你或管理员选择的 S3、R2、MinIO、WebDAV、邮件备份、Webhook、MCP 客户端、外部图片及剪藏来源等服务，可能接收与功能有关的数据。外部图片加载也可能向图片服务暴露访问请求及网络信息。外部服务各自负责其平台上的数据处理。

为检查或获取更新，应用可能访问 GitHub Releases 或 Microsoft Store；这些服务可能获取请求 IP、版本请求等连接信息。Microsoft Store 版本的安装、签名和更新由微软平台提供。

06 · 日志、崩溃报告与统计

Windows 桌面应用在本地记录运行与错误日志，并可能保存崩溃转储以便问题排查。当前桌面版默认不自动向项目维护者上传崩溃报告；如你主动通过 GitHub Issue、邮件或其他支持渠道发送日志，提交的内容将用于调查问题。

桌面主进程的本地日志采用按日期轮转，当前实现会在启动时尝试清理约 14 天前的主日志文件；崩溃转储、服务器日志、备份及用户提供的诊断文件可能有不同保留规则，并非均会在 14 天后删除。

微软商店、GitHub、你访问的服务端以及你选择的第三方服务，可能按各自政策记录访问或安装统计。这些由相应平台管理。

07 · 处理目的与共享范围

数据仅按实际启用或请求的功能，用于本地记录和检索、账户登录、同步协作、文件及备份管理、AI 请求、更新、故障定位与安全防护。因服务请求、安全或法律义务而进行的必要处理，以适用法律和对应服务运营者的权利义务为基础。

NOWEN 项目维护者不会仅因你在自己的设备或服务器运行开源软件就自动取得这些数据。我们不会出售用户笔记或个人信息。当你主动连接自托管服务器、在线模型、对象存储或其他服务时，相关数据会在必要范围内向你选择的接收方传输；跨境传输的风险和要求取决于你选择的服务部署地区与服务商条款。

08 · 你的选择、访问与删除权利

  • 你可以在应用内查看、修改、导出和删除自己的笔记、附件、任务及其他内容；具体操作受工作区权限限制。
  • 你可以选择仅使用本地模式，取消远程登录或关闭不需要的 AI、插件、备份及外部集成；撤销访问令牌和分享链接。
  • 远程实例中的数据应向相应服务器运营者申请查阅、更正、导出或删除；项目维护者通常无法直接操作用户自托管实例的数据库。
  • 删除应用不保证立即删除所有用户数据目录、独立备份、云端副本或商店账户记录。请检查应用数据目录及各个备份目标并按需清理。清理前注意先备份重要资料。

如需向 NOWEN 项目维护者提出隐私相关请求，可通过下方的项目支持入口联系。GitHub Issues 是公开页面，请不要在公开 Issue 中发布身份证件、密码、令牌、笔记全文或其他敏感信息。

09 · 数据安全

项目支持登录验证、权限检查、令牌管理以及部分加密与备份安全机制；用户应为远程服务器启用 HTTPS、使用强密码和两步验证、及时更新、定期备份，并谨慎授予插件访问权限。

不是所有本地数据或远程同步内容都默认采用端到端加密；某些加密笔记功能仍处于开发阶段。任何软件和网络服务都无法保证绝对安全。请自行管理设备访问权限以及服务器和第三方账号的安全。

10 · 保存期限与跨境处理

本地笔记与设置通常保存至用户删除、迁移或清理对应数据目录。服务器侧数据、备份与审计记录保存期限由实例管理员及用户设置决定；第三方 AI、云存储与同步提供商遵循其独立政策。微软商店相关安装记录由微软管理。

由于你可以选择位于不同地区的服务器和 AI 服务，内容可能在你所选择的国家或地区被处理。请在传输敏感资料前核对所选服务的所在地、条款及适用的合规要求。

11 · 未成年人

Nowen Note 是面向一般笔记和知识管理场景的工具，并非专门面向儿童提供的个人信息收集服务。未成年人应在监护人指导下使用，避免未经授权公开自己的或他人的敏感资料。涉及儿童信息处理时，服务器运营者及相关服务提供商应遵守适用法律。

12 · 政策更新

我们可能随着桌面版功能、发布渠道和法律要求的变化而更新本政策。修订后会在本页面更新生效日期；如涉及重要的数据用途或外部传输方式调整，应提供适当提示及必要选择。
