官网访问统计与隐私说明

更新日期：2026 年 10 月 28 日。本页说明官方网站访问统计，不适用于 Nowen Note Windows 客户端。

统计什么？

本站使用 Cloudflare Workers + D1 保存累计浏览（PV）和独立浏览器标识数（UV）。有效路由访问计一次，同一路径短时间内重复刷新去重。UV 是浏览器近似统计，非自然人人数。

保存哪些数据？

首次访问时浏览器在本站 localStorage 中生成随机标识。D1 只保存该标识的 SHA-256 摘要、首次/最近计数时间、最近访问的站内路由及累计 PV/UV。不将原始 IP、完整 URL 查询参数或笔记内容写入统计表；Cloudflare 基础设施可能另有安全或访问日志。

如何停止或重置？

关闭本站的本地存储权限后，本站仅读取汇总值而不上传新的访客标识。清除 nowen.cn 的网站数据可删除浏览器标识，再次启用时可能被计为新访客。问题可联系 GitHub 官网 Issues，请勿公开发布敏感信息。

可选的分析后台

站点可能另外启用 Cloudflare Web Analytics Beacon，用于后台趋势和性能分析，但不用于页脚计数。详见 Cloudflare 文档。不蒜子的历史统计不会自动迁移。
